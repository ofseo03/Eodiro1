# 어디로 (Eodiro)

서울 한 지역 안에서 날씨·이동시간·교통수단 조건에 맞는 **카페·식당·놀거리 코스**를 추천하는 웹 서비스입니다.
기능 정의는 [`docs/spec.md`](docs/spec.md) 를 기준으로 합니다.

## 지금 구현된 범위

| spec 항목 | 상태 |
| --- | --- |
| 지역·이동시간·교통수단·도보 거리 입력과 검증 (spec 2) | 구현 |
| 취향 저장 후 재사용 (기기 내 `localStorage`) | 구현 |
| 단기예보 조회와 실내 우선 추천 (spec 3) | 구현 — 인증키 필요 |
| 구간별 이동수단 결정, 택시 없는 코스 우선 (spec 3) | 구현 — 대중교통 응답 필드는 실호출 검증 전 |
| 경로 없음 / 조회 실패 / 택시 대안 구분 (spec 3) | 구현 |
| 미확인 시간·거리를 0으로 처리하지 않는 합산 (spec 3) | 구현 |
| 반경 100m 같은 카테고리 장소 교체 + 앞뒤 구간 재검증 (spec 3) | 구현 |
| 실제 보행거리 확보 | **미구현** — 현재 목록의 API 로 확보 가능한지 미확인 (spec 5) |
| 서울교통공사 최단경로 API | **미연동** — 엔드포인트·식별자 검증 필요 (spec 5) |
| 서울시 실시간 도시데이터 | **미연동** |

정직성 원칙: 확인되지 않은 값을 채워 넣지 않습니다. 실제 보행거리를 확보하지 못한 구간은
`직선거리 기준 · 실제 보행거리 미확인` 으로 표시하고, 그 코스를 '모든 조건 충족'으로 표시하지 않습니다.

## 로컬 실행

```bash
npm install
cp .env.example .env.local   # 인증키 입력
npm run dev
```

인증키가 없어도 앱은 뜹니다. 이때 장소는 `docs/spec.md` 검증을 대체하지 않는 **샘플 데이터**로 채워지고,
날씨와 대중교통 경로는 각각 '키 미설정', '경로 조회 실패'로 표시됩니다.

## Vercel 배포

1. Vercel 에서 이 저장소를 Import 합니다. 프레임워크는 Next.js 로 자동 인식됩니다.
2. Project Settings → Environment Variables 에 다음을 추가합니다.
   - `DATA_GO_KR_SERVICE_KEY` — 공공데이터포털 일반 인증키(Decoding)
   - `SEOUL_OPEN_API_KEY` — 서울 열린데이터 광장 인증키
   Production / Preview / Development 모두에 등록해야 프리뷰 배포에서도 실호출됩니다.
3. Deploy 합니다. `vercel.json` 에서 실행 리전을 서울(`icn1`)로, API 라우트 타임아웃을 30초로 지정해 두었습니다.

### 배포 전 확인

- 공공데이터포털 서비스는 신청 후 승인까지 시간이 걸리고 **일일 호출 한도**가 있습니다.
- 관광 데이터·대중교통 API 는 `http` 엔드포인트를 씁니다. 브라우저가 아니라 서버 라우트에서만 호출하므로
  혼합 콘텐츠 문제는 없지만, 클라이언트에서 직접 부르도록 바꾸지 마세요.
- 인증키는 서버 전용 환경변수입니다. `NEXT_PUBLIC_` 접두사를 붙이지 마세요.

## 구조

```
src/
  app/
    page.tsx              조건 입력 폼 + 결과 화면
    api/recommend/route.ts  코스 추천
    api/replace/route.ts    장소 교체 후보 조회 / 교체 적용
    api/regions/route.ts    지역 목록
  lib/
    types.ts              '미확인'을 타입으로 고정한 도메인 모델
    rules.ts              날씨 기준·코스 규칙 등 확정 대기 중인 상수
    config.ts             서버 전용 인증키
    geo.ts                직선거리, 기상청 격자 변환
    regions.ts            지역 경계 근사(중심+반경)
    validate.ts           입력 제약 재검증
    api/                  기상청 / 서울 관광 / 대중교통환승경로 클라이언트
    recommend/            후보 선정 · 구간 판정 · 코스 조립 · 장소 교체
  data/samplePlaces.ts    인증키 없이 화면을 확인하기 위한 샘플 데이터
```
